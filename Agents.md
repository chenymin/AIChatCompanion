# Course execution rules

- Do not automatically run tests, type checks, builds, CLI examples, dev servers, or browser checks after changing code unless the user explicitly requests execution.
- The learner manually verifies each lesson. Record implementation, mock validation, and live validation separately.
- Published lesson tags are stable. Fixes receive new commits or versioned tags; do not move existing tags.
- Never commit local credentials, local conversation data, or raw provider responses containing sensitive information.
